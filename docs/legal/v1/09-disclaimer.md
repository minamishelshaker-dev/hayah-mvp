# إخلاء المسؤولية القانوني والتقني

المعلومات العامة والنماذج المنشورة لا تمثل استشارة قانونية فردية، ولا تنشأ علاقة محام وموكل بين المستخدم والمشغل.
لا تضمن المنصة قبول النزاع أو مشاركة الطرف الآخر أو نجاح التسوية أو تنفيذ الحكم. ويتحمل كل طرف مسؤولية الحصول على مشورته القانونية المستقلة.
المحايد مستقل ومسؤول مهنياً عن مهمته. ولا تعني إتاحة مستند إلكتروني أنه يغني عن أصل ورقي أو توقيع معتمد أو إيداع أو ترجمة أو إجراء تنفيذ يفرضه القانون.

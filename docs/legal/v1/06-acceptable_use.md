# سياسة الاستخدام المقبول ومنع إساءة الاستخدام

يحظر على المستخدم:
- انتحال صفة شخص أو شركة.
- رفع مستند مزور أو معدل بصورة مضللة.
- التهديد أو الابتزاز أو التشهير أو التحرش.
- الوصول غير المصرح به أو اختبار الأمن دون إذن.
- إدخال برمجيات ضارة أو تعطيل الخدمة.
- استخراج بيانات المحايدين أو المستخدمين أو بيعها.
- التواصل المنفرد غير المصرح به مع المحكم.
- التأثير على المحايد خارج ملف النزاع.
- نشر المستندات أو الجلسات أو الأحكام السرية.
- استخدام المنصة لمنازعات وهمية أو غسل أموال أو تحصيل غير مشروع.
يجوز تعليق الحساب، وحفظ الأدلة، ومنع الوصول، وإبلاغ الجهات المختصة عند وجود التزام قانوني.
